## Overview

- **Description:** Create 3 JPA entities (MovieRating, MovieComment, CommentReaction) and their repositories with custom query methods.

## Key Insights

- Hibernate `ddl-auto: update` auto-creates tables; no migration scripts needed
- Cross-service userId stored as `Long` column (no FK constraint); same as payment-service pattern
- Existing entities use `@Data`, `@NoArgsConstructor`, `@AllArgsConstructor`, `@PrePersist` for timestamps
- `@Table(uniqueConstraints = ...)` enforces one-rating-per-user-per-movie and one-reaction-per-user-per-comment at DB level

## Requirements

### Functional
- MovieRating: stores user's 1-5 star rating per movie; unique per (movieId, userId)
- MovieComment: stores text comment per movie; supports soft-delete via status enum
- CommentReaction: stores like/dislike per comment; unique per (commentId, userId); hard-delete on toggle-off

### Non-Functional
- All entities under 60 lines each
- Use existing Lombok + JPA annotation patterns exactly
- `@PrePersist` for createdAt; separate updatedAt for editable entities (MovieRating, MovieComment)

## Architecture

```
movie_ratings    ──ManyToOne──>  movies
movie_comments   ──ManyToOne──>  movies
comment_reactions ──ManyToOne──> movie_comments
```

### Step 2: Create MovieRating entity
```java
// model/MovieRating.java
@Entity
@Table(name = "movie_ratings", uniqueConstraints = {
    @UniqueConstraint(columnNames = {"movie_id", "user_id"})
})
@Data @NoArgsConstructor @AllArgsConstructor
public class MovieRating {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)  // Don't need full Movie when reading rating
    @JoinColumn(name = "movie_id", nullable = false)
    private Movie movie;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(nullable = false)
    private Integer rating;  // 1-5, validated at service/DTO level

    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;

    @PrePersist
    public void prePersist() {
        if (createdAt == null) createdAt = LocalDateTime.now();
        updatedAt = LocalDateTime.now();
    }

    @PreUpdate
    public void preUpdate() { updatedAt = LocalDateTime.now(); }
}
```

### Step 3: Create MovieComment entity
```java
// model/MovieComment.java
@Entity
@Table(name = "movie_comments")
@Data @NoArgsConstructor @AllArgsConstructor
public class MovieComment {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "movie_id", nullable = false)
    private Movie movie;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(columnDefinition = "TEXT", nullable = false)
    private String content;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false)
    private CommentStatus status = CommentStatus.ACTIVE;

    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;

    @PrePersist
    public void prePersist() {
        if (createdAt == null) createdAt = LocalDateTime.now();
        updatedAt = LocalDateTime.now();
        if (status == null) status = CommentStatus.ACTIVE;
    }

    @PreUpdate
    public void preUpdate() { updatedAt = LocalDateTime.now(); }
}
```

### Step 4: Create CommentReaction entity
```java
// model/CommentReaction.java
@Entity
@Table(name = "comment_reactions", uniqueConstraints = {
    @UniqueConstraint(columnNames = {"comment_id", "user_id"})
})
@Data @NoArgsConstructor @AllArgsConstructor
public class CommentReaction {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "comment_id", nullable = false)
    private MovieComment comment;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(name = "is_like", nullable = false)
    private Boolean isLike;  // true=like, false=dislike

    private LocalDateTime createdAt;

    @PrePersist
    public void prePersist() {
        if (createdAt == null) createdAt = LocalDateTime.now();
    }
}
```

### Step 5: Create MovieRatingRepository
```java
public interface MovieRatingRepository extends JpaRepository<MovieRating, Long> {
    Optional<MovieRating> findByMovieIdAndUserId(Long movieId, Long userId);

    @Query("SELECT AVG(r.rating) FROM MovieRating r WHERE r.movie.id = :movieId")
    Double findAverageRatingByMovieId(@Param("movieId") Long movieId);

    @Query("SELECT COUNT(r) FROM MovieRating r WHERE r.movie.id = :movieId")
    Long countByMovieId(@Param("movieId") Long movieId);
}
```

- Custom `@Query` methods for aggregation (no N+1)
- `@PrePersist` / `@PreUpdate` handle timestamps

## Risk Assessment

- **Hibernate ddl-auto may not create unique constraints on existing tables**: Mitigated by fresh tables; Hibernate handles uniqueConstraints on CREATE
- **FetchType.LAZY on ManyToOne may cause LazyInitializationException**: Mitigated by accessing movie.id only (proxy handles without loading)

## Security Considerations

- userId stored as Long column; no FK to auth DB (cross-service pattern)
- Validation of rating range (1-5) deferred to DTO/service layer, not entity
- No sensitive data in entities
